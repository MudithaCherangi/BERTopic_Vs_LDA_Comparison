This study presents a comparative analysis of Latent Dirichlet Allocation (LDA) and BERTopic on the 20 Newsgroups dataset, with the aim of evaluating differences between probabilistic and embedding-based topic modelling approaches. LDA represents documents using a bag-of-words framework and
models topics as latent word co-occurrence distributions, whereas BERTopic leverages transformer-based embeddings, clustering, and class-based TF-IDF , weighting to construct
semantically coherent topic representations.
